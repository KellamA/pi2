### Added
- A file tool can be given a path in the conversation's scratch folder. `read`, `write`, `edit`, `list_files`, `find_files` and `search_files` take a path beginning with `$PI2_SCRATCH` or `${PI2_SCRATCH}` as that folder — the same one a shell command's `$PI2_SCRATCH` names — and answer with the real path, so it can be used again. A path beginning with any other `$` is refused and says so, which is what stops a folder named `$HOME` being made by mistake; a `$` in the middle of a path is still just a character in a name.
