### Added
- A file tool can be given a path in the conversation's scratch folder. `read`, `write`, `edit`, `list_files`, `find_files` and `search_files` take a path beginning with `$PI2_SCRATCH` or `${PI2_SCRATCH}` as that folder — the same one a shell command's `$PI2_SCRATCH` names — and say what they found there: `read`, `write` and `edit` answer with the real path, which can be used again, and `list_files`, `find_files` and `search_files` name what they list, find or search `$PI2_SCRATCH/…`, which can be given straight back as the path. A path beginning with any other `$` is refused and says so, which is what stops a folder named `$HOME` being made by mistake; a `$` in the middle of a path is still just a character in a name.
