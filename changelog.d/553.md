- An opened piece of work says where it is and offers what its state allows above its text rather than after it, so they are to hand however long the text is.
- When a project’s setting asks each time for something an agent wants to do, the request in the conversation now offers only Allow Once and Deny, as the Now tab’s card does. It offered an “always allow” as well, which the engine refused, since only the project’s Settings can stop the asking.
