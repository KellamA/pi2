### Added
- Projects (preview): a project's Settings tab lists its schedules, with New Schedule…, Edit…, Run Now, Last Run and Delete. A schedule of a project names one of its agents (the orchestrator unless you choose another), and each run is a new conversation of the project, listed with its other conversations; Last Run opens it in place of the board. A template's schedules are listed on the template's page, and an agent's page says where its schedules show.
- Projects (preview): schedules made before projects, on an agent whose folder has a project, now run as that project's copy of the agent while the preview is on, and are listed in that project. With the preview off they run as before.
