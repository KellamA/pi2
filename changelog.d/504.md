### Fixed
- A command an agent ran could connect to pi²'s engine as the app does and answer approvals and questions itself, its own included, or turn on Allow everything. Now the engine takes those answers only from the pi² app, which it tells from any other program by macOS's code signature, and an agent that tries is told to ask you. A command can still change an agent's settings that way, or write pi²'s data folder; see "Who may answer for the person" in docs/architecture.md.
