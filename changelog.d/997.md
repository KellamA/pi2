### Changed
- The Devices page's log of what a paired iPhone did keeps the phone's own record when it is flooded: the same request about the same thing (the same file, the same title), refused or failing again within a minute, is one entry with a count and the last time (a refusal for a text's size whatever the size), while requests about different things keep an entry each; and refusals and failures can no longer push out what the phone did, such as the files it was shown. An attach refused for a Face ID signature neither of the phone's keys made now reads differently in the log from one signed by its new key that waits to be accepted.
- A secret held in a variable as a URL no longer hides every other link on a paired iPhone, nor makes every approval with a link one the phone may only deny: its scheme and `www.` are passed over when the Mac looks for it, so only links to the same host are still hidden. The cost: where such a value is cut before the rest of it, its scheme and up to 7 characters after it can show. A text that ends partway into a key now hides that part on the phone.
