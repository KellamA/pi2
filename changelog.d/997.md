### Changed
- The Devices page's log of what a paired iPhone did keeps the phone's own record when it is flooded: repeated refusals and failures of one request within a minute are one entry with a count and the last time (a refusal for a text's size whatever the size), and refusals and failures can no longer push out what the phone did, such as the files it was shown. An attach refused for a Face ID signature neither of the phone's keys made now reads differently in the log from one signed by its new key that waits to be accepted.
- A secret held in a variable as a URL no longer hides every other link on a paired iPhone, nor makes every approval with a link one the phone may only deny: its scheme and `www.` are passed over when the Mac looks for it, so only links to the same host are still hidden. A text that ends partway into a key now hides that part on the phone.
