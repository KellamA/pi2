### Added
- A model set up to run on this Mac is offered in the model selector under On this Mac, and runs when it is used: pi² starts it when a conversation with it is opened, created, switched to it or set working, shares it between conversations, and stops it a minute after the last one is closed, archived or switched away. A message sent while it loads waits and is answered; one that cannot start says why and points at its log. Activity and the menu bar show a loaded model, since when and how much memory it holds, with Stop.
