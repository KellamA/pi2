### Added
- Settings › General has a **Default model for new agents**, with its thinking level: the model every agent with no model of its own runs on, which is every new agent until you choose one in its settings, whether made by hand, in a project, by an orchestrator, or as a new project's orchestrator. Agents follow it, so changing it changes what they start their next conversation on; a conversation already started keeps its model. Left at **The model used last**, it works as before, following the model you last picked in a conversation; once chosen, picking a model in a conversation changes only that conversation. If the chosen model is switched off or its provider signed out, agents start on another until it is back, and the setting says which. An agent's page now names the model App default stands for.
