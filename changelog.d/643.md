### Added
- Projects (preview): you can start a conversation with one of a project's agents. Use New Conversation on its row in the Agents tab, on its page, or in the menu of its working row in the sidebar; the conversation opens in place of the board. ⌘N opens a short picker of the shown project's agents: type a name and press Return. On the Dashboard it asks for the project first. File › New Conversation With lists the project's agents. For the orchestrator, each of these is Start Fresh, which asks first.
- Projects (preview): Make Orchestrator… on an agent's row in the Agents tab makes that agent the project's orchestrator. It asks first, saying that a new conversation is started fresh and the present one is kept.
- Projects (preview): the command palette finds a project's agents, its conversations and its board's tabs by project, such as "Demo project › Atlas" or "Demo project › Work", and opens them in the project.
- Projects (preview): a working agent's row in the sidebar and the Agents tab's rows show Allow everything's red tag, as template rows do.
