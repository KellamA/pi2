### For contributors
- **CI runs a job again by itself when no runner took it.** GitHub cancels a job that no runner picked up in time, as happens to the macOS jobs when it is short of macOS runners, and the check counted as failed until someone ran it again. Now it is run again by itself, up to three times. Only that case: a real failure is never retried. See [docs/development.md](docs/development.md#ci) (#245).
- **A pull request that changes only the docs skips the macOS jobs.** One that changes only `docs/`, `changelog.d/`, the top-level Markdown files or `app/VERSION` no longer waits for a macOS runner: the engine's tests and the app's build are skipped, and their required checks pass (#245).
