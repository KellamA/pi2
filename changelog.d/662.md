### Changed
- An agent of a project can give the `work` tool a long text, such as a pull request's body, as a file: `text_file` takes a path in the conversation's folder or its scratch folder (`$PI2_SCRATCH/…`), and the file's contents are posted as `text` would be, with the agent's line, the same limits and the home folder shown as `~`. A `text` that is only the path of a file is now refused, saying to use `text_file`, where before the path itself was posted as the pull request's body.
