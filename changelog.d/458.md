### For contributors
- Projects (a preview): the engine can carry today's agents and conversations over into projects (`engine/src/carryover.ts`, docs/projects.md section 9). `projects.carryOver` with `dryRun` reports what would go where, with a fingerprint; turning the preview on runs that plan only if it is still the same, after a backup, one project per commit, so a second run changes nothing. Agents are copied into each project, with their notes for the copy alone and their variables' values copied into the Keychain in a step retried at every start and with `projects.retrySecrets`. Conversations made later with the preview on go into their folder's project. Nothing the old screens read is changed, so switching the preview off shows everything as before. A refused request may now carry `data` beside its message, and the app's `EngineError` keeps it. Tests that need a conversation in no project with the preview on use one whose project was deleted (`previewOnLeavingOut` in `engine/test/patience.ts`).
