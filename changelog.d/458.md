### For contributors
- Projects (a preview): the engine can carry today's agents and conversations over into projects (`engine/src/carryover.ts`, docs/projects.md section 9). `projects.carryOver` with `dryRun` reports what would go where, with a fingerprint; turning the preview on runs that plan only if it is still the same, after a backup, one project per commit, so a second run changes nothing. Agents are copied into each project, with their notes for the copy alone (recorded per project, so a project that gets a copy later gets them too) and their variables' values copied into the Keychain in a step retried at every start and with `projects.retrySecrets`. A project given the default orchestrator gets its conversation only when it is first opened (`projects.startFresh`). Conversations made later with the preview on, forks among them, go into their folder's project, checked against its limits; one left in no project is carried at the next start. A conversation whose project was deleted is in no project: it runs as its own agent, hands work to templates and reads its agent's notes. Nothing the old screens read is changed, so switching the preview off shows everything as before. Tests that need a conversation in no project with the preview on use one whose project was deleted (`previewOnLeavingOut` in `engine/test/patience.ts`).
